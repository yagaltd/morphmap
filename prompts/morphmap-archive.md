# /morphmap-archive

Load skill: morphmap-archive

Archive completed (✅) branches to keep the main map lean. Extracts branch subtree to .morphmap/archive/<date>-<slug>.md, replaces with summary link in main map. Preserves full detail, keeps main map clean.

Usage:
  /morphmap-archive <branch-name>    Archive specific ✅ branch
  /morphmap-archive --all            Archive all ✅ ## branches
